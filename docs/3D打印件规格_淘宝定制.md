## 1️⃣ 髋关节支架 (Hip Bracket)

### 用途
固定在髋舵机 (DS3218) 上，提供 40mm 侧向偏移，用于安装肩舵机。

### 尺寸规格
```
外形尺寸: 20mm (X) × 40mm (Y) × 50mm (Z)
壁厚: 3mm
材料: PLA
颜色: 深灰色 或 黑色（推荐）
填充率: 30%
层高: 0.2mm
支撑: 需要
```

### 详细结构
```
┌─────────────────────────┐  ← 顶部 (50mm高)
│         U型槽           │
│   ┌─────────────┐       │
│   │   舵机安装  │       │  ← 内部容纳DS3218舵机
│   │   腔体      │       │     (40.7×20.2×36.2mm)
│   │             │       │
│   └─────────────┘       │
│                         │
│   ○ M3孔 ×4             │  ← 舵机固定孔
│                         │
└─────────────────────────┘
    20mm (宽)  40mm (深)

关键孔位:
  - 舵机固定孔: 4× Φ3.2mm (M3螺丝通孔)
    位置: 标准DS3218安装孔距 (48mm×10mm)
  - 轴承孔: 2× Φ10.5mm (容纳MR105ZZ轴承)
    位置: 对称分布于两侧壁
```

### 参考图（ASCII示意）
```

    50mm                    20mm
    │                       │
    ├─┐                 ┌───────┐
    │ │                 │   ○   │ ← 轴承孔
    │ │ ← U型槽          │       │
    │ │                 │  ███  │ ← 舵机腔体
    │ │                 │  ███  │
    │ │                 │   ○   │

    └─20mm                └─40mm
```

## 5️⃣ 舵机摇臂转接件 (Servo Horn Adapter)

### 用途
连接DS3218舵机的摇臂与腿杆，传递扭矩。

### 尺寸规格
```
形状: 扁平圆盘 + 连接臂
直径: Φ25mm
厚度: 4mm
材料: PLA
颜色: 黑色
填充率: 40% (需要强度)
层高: 0.15mm (精度要求高)
支撑: 不需要
```

### 详细结构
```
俯视图:
        ┌───────┐
        │  ○○○  │  ← 摇臂孔 (匹配DS3218)
    ┌───┤   │   ├───┐
    │   │   ●   │   │  ← 中心轴孔 Φ6mm
    │   │       │   │
    └───┤       ├───┘
        │  ○○○  │  ← M2孔 ×4 (固定摇臂)
        └───────┘
          Φ25mm

侧视图:
    ═══════════  ← 4mm厚
    │         │
    ○    ●    ○  ← M2螺丝孔位
```

### 关键尺寸
```
- 外径: Φ25mm
- 厚度: 4mm
- 中心轴孔: Φ6mm (配合舵机轴)
- M2孔位: 4个, Φ2.2mm, 沿圆周分布
- 摇臂槽: 需要匹配DS3218原厂摇臂轮廓
```

**注**: 此部件最好使用原厂摇臂，若打印需要精确测量DS3218摇臂尺寸。

## 📏 打印参数总结

### 推荐打印参数
| 参数 | 值 | 备注 |
|------|-----|------|
| 材料 | PLA | 普通PLA即可，不需要PLA+ |
| 喷嘴温度 | 200-210°C | 根据品牌调整 |
| 热床温度 | 60°C | 防翘边 |
| 层高 | 0.2mm | 平衡速度和质量 |
| 壁厚 | 3层 (1.2mm) | 保证强度 |
| 顶底层 | 5层 | - |
| 打印速度 | 50mm/s | 保证精度 |
| 回抽 | 启用 | 减少拉丝 |

### 支架类部件（髋、膝支架）
- 填充率: **30%**
- 填充图案: 三角形/蜂窝
- 支撑: **需要** (打印时U型向上)
- 粘附: Brim 5mm

### 腿杆类部件（上、下腿连杆）
- 填充率: **20%**
- 填充图案: 格栅
- 支撑: **不需要** (平放打印)
- 粘附: Raft 或 Brim

### 小件（摇臂转接）
- 填充率: **40%**
- 层高: **0.15mm** (精度优先)
- 支撑: 不需要

## 📐 给淘宝卖家的技术要求

### 基本要求
```
✅ 材料: PLA (普通即可)
✅ 打印机: FDM (不需要光固化)
✅ 精度: ±0.2mm
✅ 后处理: 去除支撑，轻微打磨
✅ 测试: 所有M3孔位需要能通过M3螺丝 (Φ3mm)
```

### 质量检查标准
```
1. 尺寸偏差: ±0.5mm以内
2. 孔位偏差: ±0.2mm以内 (关键)
3. 表面: 无明显拉丝、层纹平整
4. 强度: 支架U型槽不能掰断
5. 腿杆: 两端连接耳平行度 < 1mm
```

### 包装清单核对
```
□ 髋关节支架 × 4 (标记: FL, FR, RL, RR)
□ 膝关节支架 × 4 (标记: FL, FR, RL, RR)
□ 上腿连杆 × 4 (绿色/白色)
□ 下腿连杆 × 4 (绿色/白色)
□ 舵机摇臂转接 × 12 (或使用原厂摇臂)
```
