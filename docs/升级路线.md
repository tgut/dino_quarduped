## Phase 2: 总线舵机升级（精度提升）

### 升级内容

| 替换 | 旧 | 新 | 变化 |
|------|----|----|------|
| 舵机 | DS3218 (PWM) | Feetech STS3215 (TTL 总线) | +位置反馈, +精度 |
| 驱动 | PCA9685 | UART 串口直连 | 去掉 I2C 瓶颈 |
| 通信 | I2C → PWM (单向) | UART → TTL (双向) | 可读角度/电流/温度 |

### 关键型号选择

**推荐: Feetech STS3215**

| 参数 | DS3218 (当前) | STS3215 (升级) |
|------|-------------|----------------|
| 扭矩 | 21 kg·cm | 15 kg·cm |
| 角度范围 | 270° | 360° (连续) |
| 通信 | PWM | TTL 串行总线 |
| 位置反馈 | ❌ | ✅ 12-bit 磁编码器 (0.088°) |
| 速度反馈 | ❌ | ✅ |
| 电流反馈 | ❌ | ✅ (间接力矩) |
| 温度反馈 | ❌ | ✅ |
| 通信速率 | 50Hz (PCA9685) | 1Mbps (可达 100Hz+) |
| ID 设置 | 靠通道号 | 软件设 ID, 菊花链 |
| 单价 | ~25 元 | ~60 元 |

**备选: Dynamixel XL330-M288-T**
- Robotis 出品，生态最好，但单价 ~200 元，12 个就 2400 元

### 软件改动

```python
# Phase 1: PCA9685 PWM (单向)
kit.servo[channel].angle = target_angle  # 发了就不管了

# Phase 2: STS3215 TTL 总线 (双向)
sts.write_pos(servo_id, target_pos)      # 发指令
actual_pos = sts.read_pos(servo_id)       # 读实际位置
error = target_pos - actual_pos           # 可以做闭环!
```

### 预算增量

- 12 × STS3215: ~720 元
- TTL 转接板: ~30 元
- 减去 PCA9685 + DS3218: -315 元
- **净增: ~435 元**（总计 ~1100 元）

### 收益

- 闭环控制：知道舵机实际位置，大幅缩小 sim2real gap
- System Identification：可以测量真实的舵机响应曲线
- 过载保护：不再烧舵机
- 更高控制频率：100Hz+

## Phase 3: 铝合金结构（刚度提升）

### 升级内容

| 替换 | 旧 | 新 |
|------|----|----|
| 机身底板/顶板 | 3D 打印 PLA | 2mm 铝合金板 (CNC 或激光切割) |
| 腿部连杆 | 3D 打印 PLA | 2mm 铝合金 + 轴承 |
| 关节支架 | 3D 打印 | 铝合金折弯件 |
| 紧固件 | M3 螺丝 | M3 不锈钢 + 螺纹胶 |

### 加工方式

| 方案 | 精度 | 单价 | 适合 |
|------|------|------|------|
| 淘宝激光切割 | ±0.1mm | ~200 元/套 | 平板件 (底板/连杆) |
| 淘宝 CNC 加工 | ±0.05mm | ~800 元/套 | 复杂 3D 件 (支架) |
| 自行折弯 | ±0.5mm | ~100 元/套 | 简单 L 型支架 |

### 预算增量

- 铝合金结构件: ~500-1500 元（取决于加工方式）
- **总计: ~1600-2600 元**

### 收益

- 消除 3D 打印件的弹性形变
- 关节间隙大幅减小
- 可长期反复运动，不会断裂
- 整体重量可能更轻（铝比实心 PLA 轻）

## Phase 4: FOC 关节电机（终极方案）

### 升级内容

将总线舵机替换为一体化 FOC 关节电机模块：

| 型号选择 | 扭矩 | 通信 | 反馈 | 单价 |
|---------|------|------|------|------|
| CubeMars AK60-6 | 6 Nm | CAN | 位置+速度+力矩 | ~500 元 |
| T-Motor AK10-9 | 9 Nm | CAN | 位置+速度+力矩 | ~800 元 |
| 海力禾 MF 系列 | 可选 | CAN | 全状态 | ~300-600 元 |

### 核心变化

```
Phase 1-3: 位置控制
  目标角度 → 舵机转到位 → 完成

Phase 4: 力矩控制 (全新能力)
  目标力矩 → 关节输出力 → 可做柔顺控制
  - 碰到障碍物时"软"下来，不硬刚
  - 可以做 impedance control（阻抗控制）
  - 摔倒时自动卸力，保护结构
```

### 预算增量

- 12 × FOC 电机: ~3600-9600 元
- CAN 总线板: ~100 元
- 更大电池 (电流需求增加): ~200 元
- **总计: ~5000-12000 元**

### 收益

- 真正的力矩控制，接近 MIT Mini Cheetah 的控制架构
- 1kHz 控制频率
- sim2real gap 极小
- 可以跑最前沿的 RL 策略 (如 NVIDIA Isaac Lab 训练的)

## 升级决策树

```
Q1: 仿真中的算法已经跑通了吗？
  ├── 否 → 留在 Phase 1，先跑通仿真
  └── 是 → Q2

Q2: 实机能站稳、慢走了吗？
  ├── 否 → 留在 Phase 1，用 05_stand_test.py 校准
  └── 是 → Q3

Q3: sim2real gap 导致 RL 策略无法部署？
  ├── 主要是角度不准 → 升级 Phase 2 (总线舵机)
  ├── 主要是结构变形 → 升级 Phase 3 (铝合金)
  └── 需要力矩控制 → 升级 Phase 4 (FOC)
```
