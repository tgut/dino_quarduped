## 框架结构

### 机身框架（亚克力激光切割）

两块亚克力板（3mm 厚）通过铜柱连接形成三明治结构：

```
  顶板（3mm 亚克力）：
  ┌────────────────────────────────────────┐
  │  ○          ○           ○          ○   │  ← M3 铜柱孔位
  │     ┌──────────┐   ┌──────────┐        │
  │     │ 树莓派   │   │  电池    │        │
  │     │ 安装位   │   │ 魔术贴   │        │
  │     └──────────┘   └──────────┘        │
  │  ○    ┌────────┐                   ○   │
  │       │PCA9685 │   ┌──────┐            │
  │       │ 安装位 │   │MPU6050│           │
  │       └────────┘   └──────┘            │
  │  ○          ○           ○          ○   │
  └────────────────────────────────────────┘
      200mm × 110mm

  底板（3mm 亚克力）：
  ┌────────────────────────────────────────┐
  │  ◎          ◎           ◎          ◎   │  ← 舵机安装孔
  │                                        │  （四角安装髋关节舵机）
  │  ○          ○           ○          ○   │  ← 铜柱孔位
  │                                        │
  │        ████████████████████            │  ← 走线槽
  │                                        │
  │  ○          ○           ○          ○   │
  │                                        │
  │  ◎          ◎           ◎          ◎   │
  └────────────────────────────────────────┘
      200mm × 110mm

  铜柱高度：30mm（M3 × 30mm 黄铜铜柱）
  机身总高：3 + 30 + 3 = 36mm
```

## 组装步骤

```
第一阶段：机身框架
  1. 激光切割顶板和底板
  2. 在底板上安装 8 根 M3 铜柱
  3. 将 4 个髋关节舵机安装到底板四角
  4. 安装顶板

第二阶段：腿部组装（×4 条腿）
  1. 将肩关节舵机装入髋关节支架
  2. 髋关节支架连接到髋关节舵机摇臂
  3. 大腿连杆连接到肩关节舵机摇臂
  4. 膝关节舵机安装在大腿/小腿连接处
  5. 小腿连杆连接到膝关节舵机摇臂
  6. 底部压入硅胶脚垫

第三阶段：电子元件
  1. PCA9685 安装在顶板上（M2.5 铜柱）
  2. MPU6050 安装在机身中心（双面胶）
  3. 树莓派 3B 安装（M2.5 铜柱）
  4. 连接 I2C 总线（PCA9685 + MPU6050）
  5. 12 根舵机线连接到 PCA9685
  6. 安装 LM2596 降压模块
  7. 连接电源线路（电池 → 开关 → 降压模块）
  8. 魔术贴固定电池到顶板

第四阶段：校准
  1. 上电，验证 I2C 设备（i2cdetect）
  2. 所有舵机归中（1500μs）
  3. 在中立站姿下装配腿部
  4. 调整舵机摇臂对齐（0° = 垂直向下）
  5. 运行站立测试 → 验证高度约 150mm
  6. 运行小跑测试 → 验证稳定前进
```

## 散热考虑

- DS3218 舵机：最高工作温度 55°C
  - 持续运动会在关节处产生热量
  - 铝合金 U 型支架起到散热片作用
  - 避免连续堵转超过 5 秒
- LM2596 #2（舵机供电）：7.4V→6V @ 5A = 7W 功耗
  - 必须添加铝制散热片（大多数模块自带）
  - 或升级为 XL4016 模块（散热设计更好）
- 树莓派 3B：建议在 SoC 芯片上加装被动散热片
