## 供电架构

```
 电池 7.4V
     │
     ├──► 10A 电源开关
     │
     ├──► LM2596 #1 ──► 5V 3A ──► 树莓派 3B（通过 GPIO 5V/GND）
     │                         ├──► PCA9685 逻辑供电（3.3~5V）
     │                         └──► MPU6050 供电（3.3~5V）
     │
     └──► LM2596 #2 ──► 6V 5A ──► PCA9685 V+（舵机供电轨）
                                └──► 12个 DS3218 舵机
```

### 功耗预算

| 部件              | 电压  | 典型电流    | 峰值电流     | 备注               |
|-------------------|-------|------------|-------------|-------------------|
| 树莓派 3B          | 5V    | 0.7A       | 1.2A        | WiFi + GPIO 工作   |
| PCA9685 逻辑       | 5V    | 0.01A      | 0.02A       | 仅 I2C 逻辑        |
| MPU6050           | 3.3V  | 0.004A     | 0.004A      | 由树莓派 3.3V 供电   |
| DS3218 ×12 空闲    | 6V    | 共 0.6A    | -           | 每个空闲约 50mA     |
| DS3218 ×12 负载    | 6V    | 共 3.6A    | 12A         | 典型 300mA，峰值 1A  |
| **合计**          | -     | **约 5A**  | **约 13A**  |                    |

- 电池：5000mAh @ 7.4V → 约 37Wh
- 续航估算：37Wh / (6V × 5A) ≈ **60~90 分钟**（混合行走模式）
- 峰值电流：12A（所有舵机堵转）— 30C 电池最大放电 150A，安全

### 安全注意事项

- XT60 接头额定 60A 持续电流
- LM2596 #2（舵机供电）：持续 5A，典型负载下够用；需加散热片
- 如舵机经常堵转，建议升级为 XL4016（8A）模块
- 建议添加电池低压报警器（2S 蜂鸣器，约 ¥5）

## 通信总线

### I2C 总线（400kHz）

```
树莓派 3B（SDA=GPIO2，SCL=GPIO3）
    │
    ├──► PCA9685   地址：0x40（默认）
    │    - 16 通道，12 位 PWM
    │    - 50Hz 舵机控制频率
    │    - 使用通道 0-11（12 个舵机）
    │
    └──► MPU6050   地址：0x68（默认）
         - 6 轴 IMU（加速度计 + 陀螺仪）
         - 内部采样率 1kHz
         - 控制回路中以 100~200Hz 读取
```

## 控制回路架构

```
┌──────────────────────────────────────────────────────┐
│                    树莓派 3B                           │
│                                                       │
│  ┌─────────────┐   ┌──────────────┐   ┌───────────┐ │
│  │   步态       │──►│   逆运动学   │──►│ PCA9685   │─┤──► 舵机
│  │  生成器      │   │   求解器     │   │  驱动     │ │
│  │  (Python)   │   │  (解析法)    │   │  (I2C)    │ │
│  └──────┬──────┘   └──────────────┘   └───────────┘ │
│         │                                             │
│  ┌──────┴──────┐                                      │
│  │ IMU 读取    │◄─────────────────────────────────────┤──► MPU6050
│  │  + PID 控制 │                                      │
│  │ (偏航/俯仰) │                                      │
│  └─────────────┘                                      │
│                                                       │
│  目标：50Hz 控制回路（每周期 20ms）                      │
└──────────────────────────────────────────────────────┘
```

### 软件分层（树莓派端）

