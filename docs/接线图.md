═══════════════════════════════════════════════════════════════════
                     I2C 总线接线
═══════════════════════════════════════════════════════════════════

  树莓派 3B GPIO 排针
  ┌─────────────────────────────────────┐
  │  Pin 1 (3.3V)  ──────► MPU6050 VCC │
  │  Pin 2 (5V)    ──────► PCA9685 VCC │
  │  Pin 3 (SDA/GPIO2) ─┬► PCA9685 SDA│
  │                      └► MPU6050 SDA│
  │  Pin 5 (SCL/GPIO3) ─┬► PCA9685 SCL│
  │                      └► MPU6050 SCL│
  │  Pin 6 (GND)   ──┬──► PCA9685 GND │
  │                   ├──► MPU6050 GND │
  │                   └──► LM2596 GND  │
  │  Pin 9 (GND)   ──────► (备用 GND)  │
  └─────────────────────────────────────┘

  注意：I2C 总线需要 SDA 和 SCL 各接 4.7kΩ 上拉电阻
       （PCA9685 模块通常已自带上拉电阻）

═══════════════════════════════════════════════════════════════════
                     MPU6050 接线
═══════════════════════════════════════════════════════════════════

  MPU6050（GY-521 模块）
  ┌────────────────────────────────────┐
  │  VCC  ◄── 3.3V（树莓派 Pin 1）     │
  │  GND  ◄── GND （树莓派 Pin 6）     │
  │  SDA  ◄── SDA （树莓派 Pin 3/GPIO2）│
  │  SCL  ◄── SCL （树莓派 Pin 5/GPIO3）│
  │  AD0  ──► GND（I2C 地址 = 0x68）   │
  │  INT  ──► （可选：树莓派 GPIO17）    │
  │  XDA  ──► 悬空                      │
  │  XCL  ──► 悬空                      │
  └────────────────────────────────────┘

  在机器人机身上的安装方向：
  ┌─────────────────────┐
  │      MPU6050         │  X 轴 → 机器人前进方向
  │   ┌──────────┐      │  Y 轴 → 机器人左方
  │   │  X →     │      │  Z 轴 → 机器人上方
  │   │  Y ↑     │      │
  │   │  Z ⊙ (上)│      │  芯片面朝上平放在机身板上，
  │   └──────────┘      │  排针朝向尾部
  └─────────────────────┘


═══════════════════════════════════════════════════════════════════
                     舵机接线（DS3218）
═══════════════════════════════════════════════════════════════════

  每个 DS3218 舵机有 3 根线：
  ┌──────────────────────────────────┐
  │  棕色 (GND)   ──► PCA9685 GND   │  （连接 6V 供电轨）
  │  红色 (VCC)   ──► PCA9685 V+    │  （6V 舵机供电）
  │  橙色 (信号)  ──► PCA9685 PWM   │  （对应通道 0-11）
  └──────────────────────────────────┘

  PWM 参数：
  - 频率：50Hz（周期 20ms）
  - 脉宽范围：500μs ~ 2500μs（DS3218 对应 270°）
  - 中位：1500μs = 135°（归中位置）
  - 分辨率：12 位（4096 级）

  角度映射关系：
  ┌──────────────────────────────────────────┐
  │  500μs  → 0°     （PCA9685 值：约 102）   │
  │  1500μs → 135°   （PCA9685 值：约 307）   │
  │  2500μs → 270°   （PCA9685 值：约 512）   │
  │                                           │
  │  弧度换算：angle_rad = (pwm_μs - 500)      │
  │           × (270°/2000μs) × (π/180°)      │
  └──────────────────────────────────────────┘

                        后方（尾部）

  元件布局说明：
  - 树莓派 3B：偏左居中，USB 口朝左方便插拔
  - PCA9685：居中，靠近所有舵机延长线
  - MPU6050：机身正中心（重心位置），水平安装
  - 电池：偏右居中（最重，靠近重心）
  - LM2596 降压模块：电池旁边，叠放或并排
  - 电源开关：后边缘，方便操作

  重量分配目标：
  - 机身 + 电子元件：约 300g（居中）
  - 电池：约 280g（偏右居中）
  - 12 个舵机 × 60g：约 720g（分布在四条腿上）
  - 总重：约 1.5kg（与 URDF 模型 mass=1.5 一致）


═══════════════════════════════════════════════════════════════════
                     走线规划
═══════════════════════════════════════════════════════════════════

  舵机延长线（每根 30cm）：
  - 沿机身底部走线槽布线
  - 每条腿 3 根线束扎在一起（3 线 × 4 腿 = 12 根线）
  - 每隔 3cm 用扎带固定，防止缠绕

  电源线（14AWG 硅胶线）：
  - 电池 → 开关：10cm，红+黑
  - 开关 → LM2596 #1：8cm
  - 开关 → LM2596 #2：8cm
  - LM2596 #2 → PCA9685 V+：5cm（尽量短，减少压降）

  I2C 信号线（杜邦线）：
  - 树莓派 → PCA9685：8cm（4 根线：VCC/GND/SDA/SCL）
  - 树莓派 → MPU6050：6cm（4 根线：VCC/GND/SDA/SCL）
  - I2C 信号线要远离舵机电源线（防止电磁干扰）
