## 4. 当前 URDF 验证（更新后）

### 快速验证脚本

```bash
cd /Users/tgut/Documents/code/dino_quadruped
python3 << 'EOF'
import xml.etree.ElementTree as ET
import pybullet as p
import pybullet_data
import time

# 1. 验证 XML 语法
tree = ET.parse('urdf/dino_quadruped.urdf')
root = tree.getroot()
print(f"✓ URDF 语法正确")
print(f"✓ 链接总数: {len(root.findall('link'))}")
print(f"✓ 关节总数: {len(root.findall('joint'))}")

# 2. PyBullet 加载测试
pc = p.connect(p.GUI)
p.setGravity(0, 0, -9.81)
p.setAdditionalSearchPath(pybullet_data.getDataPath())
plane = p.loadURDF("plane.urdf")

robot = p.loadURDF(
    "urdf/dino_quadruped.urdf",
    basePosition=[0, 0, 0.3],
    useFixedBase=False
)

print(f"✓ PyBullet 加载成功")
print(f"✓ 机器人ID: {robot}")

# 3. 检查新增支架是否加载
num_joints = p.getNumJoints(robot)
brackets = []
for i in range(num_joints):
    info = p.getJointInfo(robot, i)
    link_name = info[12].decode('utf-8')
    if 'bracket' in link_name:
        brackets.append(link_name)

print(f"✓ 支架 links: {len(brackets)} 个")
for b in brackets:
    print(f"  - {b}")

# 保持窗口打开10秒
print("\n可视化窗口已打开（10秒后自动关闭）...")
for i in range(240):
    p.stepSimulation()
    time.sleep(1./240.)

p.disconnect()
print("✓ 验证完成")
EOF
```

## 6. 常见问题

### Q: URDF 加载报错 "ParseError"
**A**: 检查 XML 标签是否闭合，使用 `xmllint urdf/dino_quadruped.urdf` 验证

### Q: PyBullet 窗口无法显示
**A**: 
```bash
# macOS 需要允许屏幕访问
# 系统设置 → 隐私与安全 → 屏幕录制 → 允许 Terminal

# 或使用无头模式
p.connect(p.DIRECT)  # 替代 p.GUI
```

### Q: Three.js 页面不显示模型
**A**: 
- 检查浏览器控制台错误
- 确保文件路径正确（使用相对路径）
- Chrome 需要 `--allow-file-access-from-files` 标志

### Q: DXF 文件尺寸单位不对
**A**: LibreCAD 中检查单位设置（Edit → Application Preferences → Units）
- 应为 Millimeters (mm)
