# 恐龙四足机器人 - 腿部结构详细说明

## 概述

每条腿由 **3 个关节** 和 **3 个舵机** 组成，形成一个 **3 DOF（自由度）** 的开链机制。

```
机身底板
  ↓ (髋关节 - X轴转)
髋部输出
  ↓ (肩关节 - Y轴转)
上腿杆 (100mm)
  ↓ (膝关节 - Y轴转)
下腿杆 (100mm)
  ↓ (固定)
脚垫 (15mm球)
```

## 关节详细说明

### 1. 髋关节 (Hip Joint)

**功能**: 控制腿的 **左右摆动**（外展/内收）

```
┌─────────────────────────────────────┐
│ 舵机信息:                            │
│  - 型号: DS3218                      │
│  - 安装: 底板四角 (±80mm, ±55mm)   │
│  - 旋转轴: X轴 (长轴方向)           │
│  - 转矩: 21 kg·cm @ 6V              │
│  - 速度: 60°/0.16s @ 6V             │
│  - 控制: PCA9685 CH0-3              │
│                                      │
│ 关节范围 (仿真):                    │
│  - 下限: -0.5 rad = -28.6°          │
│  - 上限: +0.5 rad = +28.6°          │
│  - 中心位置: 0 rad (腿垂直向下)   │
│  - 最大摆动: ±28.6°                │
│                                      │
│ 机械连接:                           │
│  ├─ 舵机壳体: 固定在底板            │
│  ├─ 舵机摇臂: 连接到 U 型支架       │
│  ├─ U 型支架: 铝合金, 40mm 侧向偏移 │
│  └─ 轴承支撑: MR105ZZ ×2            │
│     (形成双支撑结构)                │
└─────────────────────────────────────┘

尺寸参考 (mm):
  舵机安装孔距: 50×20 (底板标准)
  U 型支架间距: 40 (优化侧摆稳定性)
  舵机体积: 40.7(L) × 20.2(W) × 36.2(H)
```

**仿真质量分配**:
- 髋关节舵机: 60g × 4 = 240g (总)
- 单条腿髋部质量: 60g

## 四条腿的配置

| 腿部位置 | 髋关节CH | 肩关节CH | 膝关节CH | 备注 |
|---------|---------|---------|---------|------|
| **FL** (左前) | CH0 | CH4 | CH8 | 前进主动腿 |
| **FR** (右前) | CH1 | CH5 | CH9 | 前进主动腿 |
| **RL** (左后) | CH2 | CH6 | CH10 | 后腿跟随腿 |
| **RR** (右后) | CH3 | CH7 | CH11 | 后腿跟随腿 |

**对角步态配对**:
- **第1组**: FL (左前) + RR (右后) → 同步摇臂
- **第2组**: FR (右前) + RL (左后) → 同步摇臂
- 相位差: 180° (两组交替)

## 运动学参数

### 正向运动学 (Forward Kinematics)

每条腿的末端执行器(脚垫)位置由3个关节角度决定:

```
θ_hip    = 髋关节转角 (X轴旋转)
θ_shoulder = 肩关节转角 (Y轴旋转)
θ_knee   = 膝关节转角 (Y轴旋转)

脚垫相对身体的位置:
  X = 40·sin(θ_hip)
  Y = 40·cos(θ_hip) + 100·sin(θ_shoulder) + 100·sin(θ_shoulder + θ_knee)
  Z = -40·cos(θ_hip) + 100·cos(θ_shoulder) + 100·cos(θ_shoulder + θ_knee)

(简化模型, 实际包含舵机偏移和装配间隙)
```

### 可达工作空间

```
站立范围:
  脚垫 X 范围: ±60mm (左右)
  脚垫 Y 范围: -50mm 到 +100mm (前后)
  脚垫 Z 范围: -200mm 到 -50mm (高度)

行走范围:
  单步长: 80-120mm
  步高: 30-50mm
  站距: 190mm (4脚与地面同时接触)
```

## 装配关键点

1. **髋关节**
   - U型支架的40mm侧向偏移是关键，影响腿的工作范围
   - 双轴承支撑确保刚性和精度
   - 螺丝要拧紧，但不要过度

2. **肩膝关节**
   - 两个Y轴关节形成串联机制
   - 肩关节转角×膝关节转角的复合运动产生抬腿效果
   - 膝关节的反向范围限制(-149°~-5.7°)模拟真实膝盖的单向弯曲

3. **腿长配置**
   - 上腿100mm + 下腿100mm = 200mm总长
   - 脚垫直径15mm
   - 站立高度约150mm(机身36mm + 腿长200mm - 地面间隙)

4. **重心平衡**
   - 肩膝舵机靠下方，利于重心后移
   - 电池位置可前后移动调整俯仰稳定性
   - 目标重心: 机身板中心正上方30mm处
