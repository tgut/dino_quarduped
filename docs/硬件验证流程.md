# 恐龙四足机器人 - 硬件验证流程

从收到配件到机器人行走的完整流程指南。
验证脚本位于 `hardware/` 目录，需在树莓派上执行。

---

## 前置准备

### 树莓派环境配置

```bash
# 1. 启用 I2C
sudo raspi-config
# → Interface Options → I2C → Enable
# → 重启

# 2. 安装 Python 依赖
pip3 install adafruit-circuitpython-pca9685 adafruit-circuitpython-servokit smbus2

# 3. 验证 I2C 工具可用
sudo apt install -y i2c-tools
i2cdetect -y 1
```

### 工具清单

- 万用表（调 LM2596 电压、排查断路）
- 十字/内六角螺丝刀（M2、M3）
- 尖嘴钳
- 热风枪或打火机（热缩管）
- 扎带枪
- 游标卡尺（可选，检查 3D 打印件精度）

## Phase 0: 来料检验（收件当天）

> 目标：逐个验证每个配件是否正常，退换有问题的件。

### 0.1 电源模块检验

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 电池 | 充电器充满后量电压 | 8.2~8.4V（2S 锂电满电） |
| LM2596 #1 | 接 7.4V 输入，旋钮调输出 | 万用表量到 5.0V ±0.1V |
| LM2596 #2 | 接 7.4V 输入，旋钮调输出 | 万用表量到 6.0V ±0.1V |
| 开关 | 拨动开关通断 | 万用表通断档有响 |
| XT60 | 检查公母头配对 | 插拔顺畅，不松动 |

⚠️ **LM2596 调压必须在无负载下完成，调好后再接入树莓派/PCA9685。**

### 0.2 I2C 设备检验

先最小接线（树莓派 + PCA9685 + MPU6050），运行扫描：

```bash
python3 hardware/01_i2c_scan.py
```

预期输出：
```
发现 2 个设备:
  0x40 -> PCA9685 (舵机驱动板)
  0x68 -> MPU6050 (IMU 惯性测量单元)

  [OK] PCA9685 (0x40)
  [OK] MPU6050 (0x68)

所有设备就绪，可以继续下一步！
```

**未检测到设备的排查：**

| 现象 | 排查 |
|------|------|
| 完全无设备 | 检查 raspi-config 是否启用 I2C；检查 SDA(Pin3)/SCL(Pin5)/GND(Pin6) 接线 |
| 只有 0x40 | MPU6050 接线问题，确认用 3.3V 供电（不是 5V） |
| 只有 0x68 | PCA9685 接线问题，确认 VCC 接 5V |
| 地址不对 | 检查 MPU6050 的 AD0 引脚是否接 GND（地址 0x68），悬空则为 0x69 |

### 0.3 舵机逐个检验

将舵机逐个接到 PCA9685 的 CH0，测试能否正常转动：

```bash
# 测试单个舵机（全行程扫描）
python3 hardware/02_servo_test.py --channel 0 --sweep
```

每个舵机应该：
- 从 0° 平滑扫到 270° 再扫回来
- 无异响、无卡顿、无抖动
- 转动后能回到归中位置

**12 个舵机全部测试**，记录有问题的编号以便退换。

### 0.4 IMU 检验

```bash
python3 hardware/04_imu_test.py --check
```

将 MPU6050 模块平放在桌面上：
- Z 轴加速度应约 9.8 m/s²
- X/Y 轴漂移应 < 1.5 m/s²
- Roll/Pitch 应接近 0°

## Phase 1: 机身框架组装（~1 小时）

> 目标：完成底板 + 铜柱 + 顶板的三明治结构。

```
步骤：
  1. 底板安装 8 根 M3×30 铜柱（螺母侧朝下）
  2. 4 个髋关节舵机用 M3×8 螺丝安装到底板四角
     └─ 注意舵机输出轴方向，参考接线图俯视图
     └─ 先不要完全拧死，留调整余量
  3. 盖上顶板，M3 螺丝固定
  4. 检查框架方正、无扭曲
```

### 验证

- [ ] 8 根铜柱牢固
- [ ] 4 个髋关节舵机固定，输出轴方向正确（参考接线图 S0/S3/S6/S9 位置）
- [ ] 顶板可以拆卸（后续需要接线）

## Phase 2: 舵机归中 → 腿部组装（~2 小时）

> 目标：先让舵机电气归中，再安装机械结构，保证零位一致。

### 2.1 全部舵机归中（关键步骤）

⚠️ **此步骤必须在安装舵机角（horn）之前完成！**

```bash
# 接好 PCA9685 和 12 个舵机的线
# 确保 6V 供电已接入 PCA9685 V+ 端
python3 hardware/03_servo_center_all.py
```

所有舵机将转到 135°（中位）。确认全部停稳后：

1. **安装舵机角**：将 horn 安装到舵机轴上，使腿部指向正下方
2. 用 M2 自攻螺丝锁紧舵机角
3. 此时机械零位 = 电气零位

### 2.2 单腿组装（×4 条腿）

每条腿从上到下：

```
髋关节舵机（已装在底板）
  ↓ 舵机角
髋关节支架（hip_bracket）── 提供侧向偏移
  ↓
肩关节舵机 ── 装入 U 型支架
  ↓ 舵机角
大腿连杆（upper_leg, 100mm）── MR105ZZ 轴承做对侧支撑
  ↓
膝关节舵机 ── 装在大腿/小腿连接处
  ↓ 舵机角
小腿连杆（lower_leg, 100mm）
  ↓
硅胶脚垫 ── 压入或粘合
```

### 验证

- [ ] 每条腿 3 个关节可以自由活动，无卡滞
- [ ] 舵机角锁紧，不松动
- [ ] 四条腿长度一致（大腿 100mm + 小腿 100mm）
- [ ] 轴承安装到位，关节无侧向晃动

## Phase 3: 电子接线（~1.5 小时）

> 目标：完成全部电气连接，参照 `docs/接线图.md`。

### 接线顺序

```
1. 电源线路（14AWG 硅胶线）
   电池 XT60 → 开关 → 分两路:
   ├── LM2596 #1 (7.4V→5V) → 树莓派 5V/GND
   └── LM2596 #2 (7.4V→6V) → PCA9685 V+ 端

2. I2C 总线（杜邦线）
   树莓派 Pin3(SDA) ─┬→ PCA9685 SDA
                      └→ MPU6050 SDA
   树莓派 Pin5(SCL) ─┬→ PCA9685 SCL
                      └→ MPU6050 SCL
   树莓派 Pin6(GND)  ─┬→ PCA9685 GND
                       ├→ MPU6050 GND
                       └→ LM2596 共地

3. 舵机线（30cm 延长线）
   CH0~CH11 按接线图顺序连接
   每条腿 3 根线束扎在一起，每隔 3cm 用扎带固定

4. 电源供电
   PCA9685 VCC ← 5V（逻辑供电）
   MPU6050 VCC ← 3.3V（树莓派 Pin1）
```

### 接线注意事项

- **I2C 信号线远离舵机电源线**，防止电磁干扰
- 电源线 LM2596 #2 → PCA9685 V+ **尽量短**（<5cm），减少压降
- 所有连接点套热缩管，防止短路
- GND 必须共地（树莓派、PCA9685、MPU6050、LM2596 共用一个地）

### 验证

接线完成后，**先不接电池**，用万用表检查：

- [ ] 5V 供电路径无短路（万用表电阻档量 5V 和 GND 之间）
- [ ] 6V 供电路径无短路
- [ ] I2C SDA/SCL 无短路到 GND

确认无误后接入电池，运行：

```bash
python3 hardware/01_i2c_scan.py  # 再次确认 I2C 设备
```

## Phase 4: 校准与验证

> 目标：让机器人站起来，走起来。

### 4.1 IMU 安装校验

将 MPU6050 安装在机身中心后：

```bash
python3 hardware/04_imu_test.py --check
```

确认：
- 芯片面朝上，X 轴朝机头方向
- Z 轴读数约 +9.8 m/s²
- 机身水平时 Roll/Pitch 接近 0°

### 4.2 站立测试

```bash
python3 hardware/05_stand_test.py
```

**检查项：**

| 检查项 | 方法 | 预期 |
|--------|------|------|
| 四脚着地 | 目视 | 四个脚垫均匀接触地面 |
| 机身水平 | IMU 或水平尺 | Roll/Pitch < 3° |
| 站立高度 | 尺量地面到底板 | 约 150mm |
| 稳定性 | 轻推机身 | 不倒、无晃动 |

### 4.3 舵机偏移校准（如果站不正）

```bash
python3 hardware/05_stand_test.py --calibrate
```

进入交互模式，逐个微调关节偏移量：

```
校准> fl_shoulder +30    # 左前肩关节正转 30μs
校准> show               # 查看当前偏移
校准> stand              # 重新站立查看效果
校准> save               # 满意后保存偏移值
```

将最终偏移值更新到 `hardware/servo_config.py` 的 `SERVO_OFFSET_US` 字典中。

### 4.4 慢速行走测试（首次必须用慢速）

```bash
python3 hardware/06_trot_test.py --slow --duration 3
```

⚠️ **安全注意：**
- 首次行走请在平坦桌面/地面上
- 手要放在机器人旁边，随时准备接住
- 准备好随时拔电池 XT60 头紧急断电

**观察项：**
- 四条腿是否交替抬放（对角步态）
- 是否向前移动（不是原地打转）
- 有无舵机异响（过载、卡顿）

### 4.5 正常速度行走

慢速测试通过后：

```bash
python3 hardware/06_trot_test.py --duration 10
```

### 4.6 参数调优

如果行走不稳，可调整参数：

| 问题 | 调整方法 |
|------|---------|
| 走路画圈/偏转 | 检查 `servo_config.py` 的 `SERVO_DIRECTION`，右侧腿应为 -1 |
| 步态不协调 | 降低频率 `--freq 30`，增大周期 `--period 0.8` |
| 抬腿不够高 | 增大 `--step-height 0.04` |
| 步幅太大摔倒 | 减小 `--step-length 0.02` |
| 舵机抖动 | 供电不足，检查 LM2596 #2 输出电流，必要时换 XL4016 |

## 常见问题排查

| 现象 | 可能原因 | 解决方法 |
|------|---------|---------|
| I2C 扫描不到设备 | 未启用 I2C / 接线错误 | `raspi-config` 启用；检查 SDA/SCL/GND |
| 舵机不转 | 6V 未供电 / 通道接错 | 检查 PCA9685 V+ 端有 6V；核对通道号 |
| 舵机抖动/嗡嗡响 | 供电电流不足 | LM2596 最大 3A，12 舵机峰值 12A → 换 XL4016 或加大电容 |
| 站不稳/倾斜 | 舵机角安装偏了 | `05_stand_test.py --calibrate` 微调偏移 |
| 走路画圈 | 左右腿方向不一致 | 修改 `servo_config.py` 的 `SERVO_DIRECTION` |
| IMU 数据乱跳 | 电磁干扰 | I2C 线远离舵机电源线；加 100nF 去耦电容 |
| 树莓派突然重启 | 电压跌落 | 舵机运动时电池压降，5V 不够 → LM2596 输入加 470μF 电容 |

## 下一步：Sim2Real Transfer

硬件验证完成后，进入 sim2real 阶段：

1. **System Identification**：用实测数据修正仿真参数
   - 称量实际零件重量 → 更新 URDF mass/inertia
   - 测量舵机响应曲线 → 更新仿真关节动力学
   - 测量 MPU6050 噪声 → 更新仿真传感器模型

2. **Domain Randomization**：在 PyBullet 训练时加入随机扰动
   - 质量 ±15%、摩擦 0.4~1.0、动作延迟 1-3 步

3. **RL 策略部署**：用 v7 PPO 模型替代固定步态生成器
   - 树莓派上用 ONNX Runtime 推理
   - 50Hz 控制循环：IMU 读取 → 模型推理 → 舵机输出
