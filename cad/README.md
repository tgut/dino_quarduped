# CAD 图纸说明

## 文件列表

| 文件 | 用途 | 板材 |
|------|------|------|
| `generate_dxf.py` | DXF 生成脚本（修改此文件后重新运行） |
| `body_top.dxf` | 顶板激光切割图 | 200×110mm, 3mm 亚克力 |
| `body_bottom.dxf` | 底板激光切割图 | 200×110mm, 3mm 亚克力 |

重新生成: `python3 cad/generate_dxf.py`

---

## 图层说明

| 图层 | 颜色 | 用途 | 激光切割操作 |
|------|------|------|------------|
| OUTLINE | 白色 | 外轮廓 | 切割（切透） |
| HOLES | 红色 | 圆孔（螺丝/扎带） | 切割（切透） |
| SLOTS | 绿色 | 矩形槽/大开口 | 切割（切透） |
| ENGRAVE | 蓝色 | 标注框/文字 | 雕刻（不切透）或不加工 |

## 组装顺序

```
Step 1: 底板安装铜柱
  底板 8×M3 孔 → 拧入 M3×30 铜柱（公头朝上）

Step 2: 底板安装髋关节舵机
  四角各 4×M3 螺丝固定 DS3218
  舵机轴穿过中央矩形槽

Step 3: 顶板安装电子元件
  - RPi 3B: 4×M2.5 铜柱+螺丝
  - PCA9685: 待实测孔距（暂用双面胶固定）
  - MPU6050: 排针座+双面胶+扎带
  - LM2596 ×2: 各 4×M3 螺丝
  - 电源开关: 穿入 Φ16.5 孔，螺母锁紧

Step 4: 合体
  顶板对准铜柱 → 8×M3 螺母锁紧
  穿线: 舵机线经走线槽/孔到达顶板 PCA9685

Step 5: 电池 + 接线
  电池放入标注区 → 魔术贴带穿槽绑紧 → 扎带加固
  按 docs/接线图.md 连接电源线路
```
