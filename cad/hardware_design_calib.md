# 硬件设计校准文档

## 📐 舵机实际尺寸（DS3218）

### 从附件截图测得的尺寸

#### 舵机本体
- **长度**: 40.5mm (1.58in)
- **宽度**: 20mm (0.78in)
- **高度**: 
  - 主体高度: 41mm (1.61in)
  - 总高度（含舵盘）: 45mm
  - 舵机底座到中心轴: 45mm

#### 舵机安装孔位
- **安装耳宽度**: 48mm (标准DS3218)
- **安装孔间距**: 10mm (底部两个孔)
- **安装孔直径**: Φ3mm (推荐 Φ3.2mm 用于 M3 螺丝)

#### 舵机摇臂（舵盘）
- **舵盘外径**: ~23.5mm
- **舵盘基座宽度**: 19.5mm
- **舵盘厚度**: ~4mm
- **中心轴直径**: Φ5-6mm
- **舵盘固定孔**: M2 螺丝，对称分布

## ⚠️ 当前 STL 设计问题分析

### 1. hip_bracket_detailed.stl（髋关节支架）

#### 当前设计尺寸
```
主体盒子: 20×40×50mm
舵机安装孔: 4 个 Φ3.2mm
轴承孔: 2 个 Φ5mm
```

#### 问题诊断

**❌ 问题 1: 主体尺寸不足**
- **当前**: 20mm (宽) × 40mm (深) × 50mm (高)
- **实际需要**: 至少 25mm (宽) × 45mm (深) × 55mm (高)
- **原因**: 舵机本体 40.5mm 长，加上安装耳 48mm，当前盒子无法容纳

**❌ 问题 2: 舵机孔位不准确**
- **当前**: 4 个孔，位置 ±8mm, ±15mm (估算)
- **实际需要**: 基于 DS3218 标准孔距 48mm × 10mm
- **修正**: 孔位应为 ±24mm (横向) × ±5mm (纵向)

**❌ 问题 3: 缺少舵机容纳空间**
- **当前**: 实心盒子 + 孔
- **实际需要**: U 型支架，中间需要挖空 42mm × 22mm × 45mm 用于容纳舵机本体

#### 修正方案
```
新尺寸:
- 主体: 26×50×60mm (增大以容纳舵机)
- 舵机容纳槽: 42×22×45mm (U型槽)
- 安装孔位置: 
  - 前左: [-24, -5, 25]
  - 前右: [24, -5, 25]
  - 后左: [-24, 5, 25]
  - 后右: [24, 5, 25]
- 轴承孔: Φ5mm (MR105ZZ 轴承外径)，位于两侧壁中心
```

## 📋 body_bottom.dxf 设计问题

### DXF 文件实际检测结果

**✅ 整体尺寸**: 200mm × 110mm（足够容纳所有元件）  
**✅ 孔数量**: 26 个圆形孔，半径 1.6mm (Φ3.2mm，适配 M3 螺丝)  
**⚠️ 舵机孔位问题**: 部分孔距不符合 DS3218 标准

### 孔位坐标分析

| 孔编号 | 坐标 (x, y) | 用途推测 | 状态 |
|-------|------------|---------|------|
| 1-3 | (10, 10), (10, 55), (10, 100) | 左侧边缘固定孔 | ✅ |
| 4-5 | (100, 10), (100, 100) | 中心线固定孔 | ✅ |
| 6-8 | (190, 10), (190, 55), (190, 100) | 右侧边缘固定孔 | ✅ |
| 9-10 | (5, 15), (5, 35) | 左前舵机孔（间距20mm） | ❌ 应为10mm |
| 11-12 | (55, 15), (55, 35) | 左前舵机孔（间距20mm） | ❌ 应为10mm |
| 13-14 | (145, 15), (145, 35) | 右前舵机孔（间距20mm） | ❌ 应为10mm |
| 15-16 | (195, 15), (195, 35) | 右前舵机孔（间距20mm） | ❌ 应为10mm |
| 17-20 | (5, 75), (5, 95), (55, 75), (55, 95) | 后腿舵机孔（间距20mm） | ❌ 应为10mm |

### ❌ 主要问题

**问题 1: 舵机安装孔间距错误**
- **当前**: 垂直间距 20mm (35-15=20)
- **标准**: DS3218 孔距应为 **10mm**
- **影响**: 舵机无法安装，孔位不对齐

**问题 2: 舵机横向间距也需验证**
- **当前**: 孔 9 到孔 11 间距 50mm (55-5=50)
- **标准**: DS3218 安装耳宽度 **48mm**
- **差距**: 2mm 偏差，需要调整

**问题 3: 树莓派/PCA9685 孔位未检测到**
- **预期**: 应有树莓派 4 个 M2.5 孔（58×49mm）
- **预期**: 应有 PCA9685 孔位
- **实际**: DXF 中未找到明显的电路板安装孔

### 修正方案

```
舵机孔位修正:
- 垂直间距: 20mm → 10mm
- 左前腿孔位: (5, 20) 和 (5, 30) [间距10mm]
- 右前腿孔位: (145, 20) 和 (145, 30)
- 同时调整横向距离为精确 48mm

新增电路板安装孔:
- 树莓派 3B: 4 个 Φ2.5mm 孔，58mm × 49mm 矩形
- PCA9685: 4 个 Φ2.5mm 孔，25.4mm × 22.9mm 矩形
- MPU6050: 4 个 Φ2mm 孔，20mm × 16mm 矩形
```

## 🔋 body_top.dxf 电池尺寸问题

### DXF 文件实际检测结果

**✅ 整体尺寸**: 200mm × 110mm  
**⚠️ 电池槽尺寸严重不足**

### 检测到的矩形区域

| 序号 | 尺寸 (长×宽) | 位置 (x, y) | 用途推测 | 状态 |
|------|------------|-----------|---------|------|
| 1 | 85×56mm | (18, 37) | 主元件区域 | ✅ |
| 2 | 25×61mm | (47.5, 0.5) | 未知 | ❓ |
| 3 | 15×20mm | (97.5, 35) | 小元件固定 | ✅ |
| **4** | **55×30mm** | **(125, 38)** | **电池槽** | **❌ 太小** |
| 5 | 15×3mm | (145, 46.5) | 走线槽 | ✅ |

### ❌ 严重问题：电池槽尺寸不足

**实际电池尺寸（从采购清单）**:
- **型号**: 格氏 ACE RedRock 5000mAh 2S 7.4V 70C
- **尺寸**: **132mm × 40mm × 17mm** (长×宽×厚)
- **重量**: ~250g
- **接口**: XT60

**当前 DXF 设计**:
- **电池槽**: 55mm × 30mm (矩形4 @ 125, 38)
- **问题**: 
  - 长度不足: 55mm << 132mm (差距 **77mm**)
  - 宽度不足: 30mm < 40mm (差距 **10mm**)
  - **结论**: 电池完全无法放入！

### 📐 修正方案

#### 方案 1: 调整电池槽尺寸（推荐）

```
新电池槽尺寸:
- 长度: 55mm → 135mm (留3mm余量)
- 宽度: 30mm → 42mm (留2mm余量)
- 位置: 需要重新规划，确保不与其他元件冲突

检查清单:
□ 电池槽位置是否与树莓派/PCA9685/舵机冲突？
□ 132mm 长度在 200mm 板上是否能横向放置？
□ 是否需要增加电池固定孔（魔术贴或尼龙扎带）？
□ XT60 接口是否有足够空间伸出？
```

#### 方案 2: 更换为更小电池（不推荐）

```
备选电池规格:
- 格氏 2200mAh 2S 7.4V
- 尺寸: ~105mm × 34mm × 16mm
- 问题: 容量减半，续航时间大幅下降
```

#### 方案 3: 电池外挂（临时方案）

```
将电池通过魔术贴固定在机身板下方:
- 优点: 不需要修改 DXF
- 缺点: 
  - 重心偏低（可能影响稳定性）
  - 增加整机高度
  - 电池易脱落
```

### 🔧 推荐实施步骤

1. **验证实际电池尺寸**
   - 收到电池后用游标卡尺实测
   - 确认 132×40×17mm 是否准确

2. **重新设计 body_top.dxf**
   - 将电池槽改为 135×42mm
   - 横向放置在机身板中央
   - 避开树莓派和 PCA9685 位置
   - 添加 4 个 Φ3mm 固定孔用于魔术贴或扎带

3. **导出新 DXF 文件**
   ```bash
   # 使用 ezdxf 修改
   python3 update_body_top_battery.py
   ```

4. **激光切割前验证**
   - 打印 1:1 纸质模板
   - 放置实际电池验证尺寸
   - 确认所有元件位置无冲突
