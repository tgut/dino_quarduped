  └────┬───┘  └────┬───┘
       │           │

  ┌─────────┐  ┌──────────┐
  │树莓派 3B │  │PCA9685 V+│
  │PCA9685  │  │(舵机供电) │
  │  VCC    │  │          │
  └─────────┘  └────┬─────┘
                    │
        ┌───────────┼───────────┐
        ↓           ↓           ↓
    [DS3218]   [DS3218]   ... [DS3218]
     舵机#1     舵机#2         舵机#12
     (6V)       (6V)           (6V)

功耗估算:
  - 树莓派 3B:     ~2.5A @ 5V  = 12.5W
  - PCA9685 逻辑:  ~0.1A @ 5V  = 0.5W
  - 12 个舵机峰值: ~12A @ 6V  = 72W (堵转)
  - 12 个舵机空载: ~0.5A @ 6V = 3W
  ─────────────────────────────────
  总功耗: 约 15-90W (取决于负载)

电池续航:
  - 5000mAh @ 7.4V = 37Wh
  - 步行状态 (30W): 约 1.2 小时
  - 静态待机 (15W): 约 2.5 小时

## 组装步骤总览

```
Step 1: 底板组装
  ├─ 安装 8×M3 铜柱到底板
  └─ 安装 4 个髋关节舵机 (4×M3 螺丝)

Step 2: 顶板组装
  ├─ 安装树莓派 3B (4×M2.5 铜柱)
  ├─ 安装 PCA9685 (4×M2 螺丝)
  ├─ 安装 2×LM2596 (各 4×M3 螺丝)
  ├─ 固定 MPU6050 (双面胶 + 扎带)
  └─ 安装电源开关 (Φ16.5mm 孔 + 螺母)

Step 3: 腿部组装
  ├─ 肩关节舵机 + U型支架 #1
  ├─ 膝关节舵机 + U型支架 #2
  └─ 组装 4 条完整的腿

Step 4: 合体
  ├─ 顶板对准铜柱 → 8×M3 螺母锁紧
  └─ 穿线: 舵机线经走线槽到 PCA9685

Step 5: 接线
  ├─ 电源线路 (电池 → 开关 → 降压 → 各元件)
  ├─ I2C 总线 (Pi → PCA9685, Pi → MPU6050)
  └─ 舵机信号线 (PCA9685 CH0-11 → 12 舵机)

Step 6: 固定电池
  └─ 魔术贴带 + 扎带固定电池到顶板
```

## 注意事项

1. **U型支架数量**: 只需 **8 个**（肩膝关节），髋关节直接螺丝固定
2. **杜邦线规格**: 母对母（树莓派排针 → PCA9685/MPU6050 排针）
3. **电源电压**: 
   - 树莓派: 5V (不能 6V！)
   - 舵机: 6V (不要超过 6.5V)
   - MPU6050: 3.3V (不能 5V！)
4. **舵机归中**: 组装前务必运行 `03_servo_center_all.py` 归中舵机
5. **I2C 地址**: 
   - PCA9685: 0x40
   - MPU6050: 0x68
