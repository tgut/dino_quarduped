# STL文件使用说明 - 给淘宝卖家

## 📦 文件清单

本目录包含两版本的 STL 文件：

### 简化版（Basic）- 仅基础几何

用于快速报价和参考，**商家需要添加孔位和细节**

| 文件名 | 用途 | 尺寸 | 数量 | 备注 |
|--------|------|------|------|------|
| `hip_bracket.stl` | 髋关节支架 | 20×40×50mm | 需打印4个 | 商家需添加孔位 |
| `knee_bracket.stl` | 膝关节支架 | 15×30×40mm | 需打印4个 | 商家需添加孔位 |
| `upper_leg.stl` | 上腿连杆 | Φ10×100mm | 需打印4个 | 商家需添加连接耳 |
| `lower_leg.stl` | 下腿连杆 | Φ8×100mm | 需打印4个 | 商家需添加脚垫孔 |
| `horn_adapter.stl` | 摇臂转接件 | Φ25×4mm | 需打印12个 | 商家需添加孔位 |

### 详细版（Detailed）- 包含所有孔位和特征

**推荐使用此版本**，商家可直接打印，无需修改

| 文件名 | 用途 | 特征 |
|--------|------|------|
| `hip_bracket_detailed.stl` | 髋关节支架 | ✓ 舵机孔 ✓ 轴承孔 |
| `knee_bracket_detailed.stl` | 膝关节支架 | ✓ 舵机孔 ✓ 轴承孔 |
| `upper_leg_detailed.stl` | 上腿连杆 | ✓ 连接耳 ✓ M3孔 |
| `lower_leg_detailed.stl` | 下腿连杆 | ✓ 连接耳 ✓ 脚垫孔 |
| `horn_adapter_detailed.stl` | 摇臂转接件 | ✓ 中心轴孔 ✓ 固定孔 |

---

## ✅ 为什么用详细版？

### 简化版 vs 详细版

| 方面 | 简化版 | 详细版 |
|------|--------|--------|
| 文件大小 | ~50 KB | ~150 KB |
| 孔位 | ❌ 需商家添加 | ✅ 已包含 |
| 建模时间 | 5分钟 | 1小时 |
| 打印难度 | 简单 | 中等 |
| 质量 | 需修改 | 可直接使用 |
| 成本 | 便宜 | 略贵 |

### 推荐方案

**强烈推荐使用详细版**，理由：
- ✅ 商家可直接打印，不需要额外建模
- ✅ 孔位精度有保证（3D 打印 ±0.2mm）
- ✅ 整体质量更好，组装时无需修改
- ✅ 避免沟通不畅导致的打印错误

## 📋 详细版 STL 特征说明

### 1. hip_bracket_detailed.stl（髋关节支架）

```
尺寸：20×40×50mm
材质：PLA（或强韧尼龙）
数量：4 个（FL/FR/RL/RR）
质量：约 50g（单个）

包含特征：
├─ 主体盒子：20×40×50mm
├─ 舵机安装孔 ×4
│  ├─ 直径：Φ3.2mm (M3螺丝)
│  ├─ 深度：5mm
│  └─ 位置：标准 DS3218 孔距（48mm × 10mm）
├─ 轴承孔 ×2
│  ├─ 直径：Φ5mm (MR105ZZ 轴承外径)
│  ├─ 深度：3mm
│  └─ 位置：两侧壁中心
└─ U 型槽底部（供商家开槽，宽 42mm × 深 22mm）
```

**打印建议**：
- 支撑：需要支撑（孔位底部）
- 方向：竖直放置
- 参数：0.15mm 层厚，100% 填充
