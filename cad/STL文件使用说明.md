## ⚠️ 重要说明

这些STL文件是**简化的基础几何体**，仅用于：
- ✅ 给卖家展示基本形状和尺寸
- ✅ 作为建模的参考底板
- ✅ 快速报价

**实际打印前，卖家需要添加**:
1. 舵机安装孔 (Φ3.2mm, M3螺丝通孔)
2. 轴承孔 (Φ10.5mm, 容纳MR105ZZ轴承)
3. 支架的U型凹槽（容纳DS3218舵机）
4. 腿杆两端的连接耳（厚5mm/4mm, 带M3孔）

## 🔧 卖家需要修改的细节

### 1. 髋关节支架 (hip_bracket.stl)

**当前**: 实心盒体 20×40×50mm  
**需要修改**:
```
1. 挖空U型槽：
   - 内部腔体: 42×22mm (容纳DS3218)
   - 深度: 从顶部向下40mm
   
2. 添加舵机固定孔 ×4:
   - 位置: 标准DS3218孔距 (48mm×10mm)
   - 直径: Φ3.2mm (M3螺丝)
   
3. 添加轴承孔 ×2:
   - 位置: 两侧壁中心
   - 直径: Φ10.5mm
   - 深度: 贯穿
```

### 2. 膝关节支架 (knee_bracket.stl)

**当前**: 实心盒体 15×30×40mm  
**需要修改**: 同髋支架，但尺寸更小

### 3. 上腿连杆 (upper_leg.stl)

**当前**: 空心圆管 Φ10×100mm ✓（基本正确）  
**需要添加**:
```
两端连接耳:
- 尺寸: 15mm宽 × 5mm厚
- M3孔: Φ3.2mm, 距边缘5mm
- 形状: 扁平矩形，从圆管两端延伸
```

**示意图**:
```
    ┌───○───┐     圆管     ┌───○───┐
    │  M3孔 │              │  M3孔 │
────┤       ├──────────────┤       ├────
    │       │  Φ10×100mm   │       │
────┤       ├──────────────┤       ├────
    └───────┘              └───────┘
    ←5mm厚→               ←5mm厚→
```

### 4. 下腿连杆 (lower_leg.stl)

**当前**: 空心圆管 Φ8×100mm ✓  
**需要添加**:
```
- 顶端连接耳: 12mm宽 × 4mm厚, M3孔
- 底端脚垫孔: Φ15mm, 深5mm（插入硅胶脚垫）
```

### 5. 摇臂转接件 (horn_adapter.stl)

**当前**: 实心圆盘 Φ25×4mm  
**需要添加**:
```
- 中心轴孔: Φ6mm (配合舵机轴)
- M2固定孔 ×4: Φ2.2mm, 沿圆周均匀分布
- 摇臂槽: 需要测量DS3218原厂摇臂轮廓
```

**建议**: 这个部件比较复杂，推荐使用原厂舵机自带的摇臂

## 🎯 质量检查标准

收到打印件后验证：

### 基本检查
- [ ] 数量正确（髋×4, 膝×4, 上腿×4, 下腿×4, 摇臂×12）
- [ ] 颜色正确（支架灰/黑, 腿杆绿/白）
- [ ] 无明显翘曲、层纹

### 尺寸检查（用卡尺测量）
- [ ] 髋支架: 20×40×50mm ±0.5mm
- [ ] 膝支架: 15×30×40mm ±0.5mm
- [ ] 上腿: Φ10×100mm ±0.5mm
- [ ] 下腿: Φ8×100mm ±0.5mm

### 孔位检查
- [ ] 所有M3孔能顺利通过M3螺丝（Φ3mm）
- [ ] 轴承孔能插入MR105ZZ轴承（外径10mm）
- [ ] DS3218舵机能插入支架U型槽

### 强度检查
- [ ] 支架U型槽不能轻易掰弯
- [ ] 腿杆连接耳无裂纹
- [ ] 管壁均匀，无薄弱点

## 📞 常见问题

### Q1: 卖家说STL文件太简单，无法直接打印？
**A**: 正确！这些是参考几何体。请发送配套的规格文档，让卖家根据文档添加孔位和细节。或者协商建模费（通常¥50-100）。

### Q2: 可以直接用SpotMicro的STL吗？
**A**: 可以尝试，但尺寸可能不匹配我们的URDF。建议：
- 访问: https://github.com/OpenQuadruped/spot_mini_mini
- 下载STL后与卖家核对尺寸是否一致

### Q3: 摇臂转接件需要打印吗？
**A**: 建议**直接使用DS3218舵机自带的原厂摇臂**，更精确更可靠。如果原厂摇臂不够长，再考虑打印转接件。

### Q4: 能否只打印支架，腿杆用铝管？
**A**: 可以！混合方案更好：
- 支架: PLA 3D打印（¥60）
- 腿杆: 铝合金圆管（¥60）
  - 淘宝搜: "6063铝管 Φ10×1.0mm" 和 "Φ8×1.0mm"
  - 需要加工: 两端钻M3孔
